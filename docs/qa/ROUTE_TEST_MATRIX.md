# TruckBill Complete Route Test Matrix

## 1. Overview & Strategy
This matrix inventories all **633 registered endpoints** in TruckBill, classified by business domain, and outlines the mandatory testing categories and verification assertions for each group.

### Applicable Testing Categories Legend
- **UNIT**: Unit test for underlying models, helper calculation, or policy.
- **API_POS**: Positive HTTP API feature test (valid payload, expected 200/201 response, database assertion).
- **API_NEG**: Negative HTTP API feature test (missing fields, invalid types, boundary failures, expected 422).
- **SEC_TENANT**: Multi-tenant isolation test (cross-tenant access denied, HTTP 403/404).
- **SEC_RBAC**: Role-based access control test (unauthorized role receives 403 Forbidden).
- **E2E_LARAVEL**: Full workflow simulation in Laravel test.
- **E2E_BROWSER**: Browser automation test via Playwright.
